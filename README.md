# youtube-studio

Yüz göstermeyen, çizimli, Türkçe bilim/tarih anlatım kanalı için üretim deposu. **Yeni bir AI oturumu `AGENTS.md`'den başlar.**

| Klasör / dosya | İçerik |
|---|---|
| `AGENTS.md` | Kurallar, roller, mevcut durum (başlangıç noktası) |
| `CHANNEL_STRATEGY.md` | Kanalın amacı, format, uzunluk, üretim ekonomisi |
| `PRODUCTION_WORKFLOW.md` | Bir videonun konudan yayına adımları |
| `STYLE_GUIDE.md` | Görsel kimlik: palet, çizgi, kompozisyon, tipografi |
| `CHARACTER_BIBLE.md` | Fasulye ve dünyanın "fasulye insanları" |
| `NARRATION_GUIDE.md` | Senaryo dili, tempo, mizah |
| `IMAGE_GENERATION_GUIDE.md` | ChatGPT ImageGen protokolü ve dosya isimlendirme |
| `reference-analysis/` | Referans kanal analizi + kimlik kararları (yalnızca metin ve özet görseller) |
| `character-references/` | Fasulye dönüş sayfası, ifadeler, pozlar, kostümler; nesne ve mekân referansları |
| `engine/` | Çizim motoru, fontlar, araçlar (`engine/tools/`), Göbeklitepe pilotu |
| `voice/` + `voice_config.json` | Değiştirilebilir seslendirme katmanı |
| `videos/NNN/` | Her video: araştırma, senaryo, anlatım, storyboard, promptlar, sahneler, durum |
